# 부산 행정동 위험 조기진단 대시보드 (Streamlit)

피그마 시안 3장(S-00 전체 · 폐업예측 팝업 · 2페이지 행정동·업종 상세)을 Streamlit으로 옮긴 것이다.

## 실행

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

브라우저가 열리면 `http://localhost:8501` 에서 확인한다.

## 화면

| 단계 | 주소 | 내용 |
|---|---|---|
| ① 전체 | `?page=overview` | 조건 선택 · 카드업종 · 위험순위 TOP 5 / 행정동 지도(클릭하면 선택) / 선택 동 카드 / 한 번에 비교하기 / 처음 들어오면 "폐업예측 한 눈에 보기" 팝업 |
| ② 행정동·업종 상세 | `?page=detail&code=2635051000` | 폐업위험률 · 예상 폐업 점포 · 위험 순위 · 상권 실측 신호 · 재단 보증현황 · 업종별 폐업위험 · 폐업위험을 높이는 원인(원그래프) · 언제부터 나빠졌나 · 주변 행정동 지도 · 주변과 비교 · 예측 신뢰도 · 점포 순증 |
| ③ 근거 확인 및 자료 다운 | `?page=evidence` | 지표별 계산 방법·출처·기준일, CSV 내려받기 |

선택한 기준월·업종·구군·행정동은 모두 주소창(쿼리)에 담긴다. 주소를 복사해 보내면 같은 화면이 열린다.

## 파일 구조

```
app.py      화면 흐름과 Streamlit 위젯
ui.py       카드·차트(HTML/SVG)와 테마 CSS
data.py     데이터 읽기 (실제 파일이 없으면 예시 데이터 생성)
assets/     busan_hd.geojson (부산 행정동 205개 경계, 2023.07 기준), logo.png
data/       sinbo_gu_upjong_2025.csv (재단 보증 실자료, 구군 × 업종 대분류, 2025년)
```

## 실제 데이터 연결

지금은 **재단 보증현황만 실자료**이고 나머지(폐업확률, SHAP, 실측 신호)는 예시 값이다.
아래 파일을 `data/` 에 넣으면 그 파일을 읽는다. 행정동코드는 10자리 문자열.

| 파일 | 열 |
|---|---|
| `model_pred.csv` | 행정동코드, 기준월(YYYYMM), 카드업종(‘전체’ 포함), 폐업확률(0~1) |
| `model_shap.csv` | 행정동코드, 기준월, 카드업종, 요인(한글 설명), 기여 |
| `dong_signals.csv` | 행정동코드, 기준월, 폐업률_6m, 카드소비_전년비, 방문인구_전년비, 영업점포수, 1년미만폐업비중, 개업_6m, 폐업_6m |

- 등급 기준(우선 확인 10% 이상 / 높음 8~10% / 주의 6~8% / 보통 6% 미만 / 판단 보류 = 영업 점포 30곳 미만)은 `data.py` 의 `GRADES`, `HOLD_MIN_STORES` 에서 바꾼다.
- 위험 신호 문장은 모델이 아니라 실측 값으로 만드는 규칙이다(`data.signals`).
- 경계 파일의 신호동(2644059000)은 이미 녹산동(2644056000)에 합쳐진 버전이다.

## 알아둘 점

- 지도 배경 타일(CartoDB)과 글씨체(Pretendard)는 인터넷에서 불러온다. 오프라인이면 기본 지도·글씨체로 보인다.
- `st.container(key=...)`, `st.pills` 를 쓰므로 Streamlit 1.42 이상이 필요하다.
- 재단 보증 실자료는 팀 내부 자료이므로 저장소를 외부에 공개하지 않는다.
